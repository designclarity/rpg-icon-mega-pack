## Provenance

All 1,273 icons are original works. No third-party artwork, sprites,
stock images, or trademarked designs were used or referenced. Each icon
was authored on a 16x16 pixel grid by an AI-assisted generation program
(see `generate/` in the source project), using an original palette and
outline style shared across the pack.
